Bedienung

Eine Note oder Pause anklicken, dann:

↑ ↓Ton höher / tiefer (bleibt in der Tonart)
Strg+↑ ↓Oktave höher / tiefer
+ - 0Halbton höher (♯) / tiefer (♭) / auflösen (♮)
C D E F G A HTon direkt setzen (B = b, also erniedrigtes h)
← →vorige / nächste Note markieren
1 … 6Ganze, Halbe, Viertel, Achtel, Sechzehntel, Zweiunddreißigstel
.Punktierung an/aus
NNote dahinter einfügen
KAkkordton hinzufügen
Pin Pause umwandeln
THaltebogen an/aus
AusdruckStaccato, Akzent, Tenuto, Fermate und Dynamik über die Knöpfe in der Leiste; sie werden beim Abspielen berücksichtigt
AkkordNote markieren, im Feld „Akkord“ eintippen (z. B. Am, Fis7, Hm, D/Fis), Enter. Leeres Feld + Enter löscht den Akkord.
LiedtextNote markieren, im Feld „Silbe“ tippen, Enter oder Leertaste springt zur nächsten Note. schrei- trennt zur nächsten Silbe, Licht_ zeichnet eine Haltelinie. Shift+Enter geht zurück.
Stimmen„Stimmen ▾“ neben „Abspielen“: einzelne Stimmen stumm schalten, solo hören oder lauter/leiser stellen.
GabelnNote markieren, „Cresc. <“ oder „Decresc. >“ drücken, dann die letzte Note der Gabel anklicken. Erneut drücken entfernt die Gabel.
EntfNote → Pause; Pause oder Akkordton → ganz entfernen
Umschalt+EntfNote ganz entfernen (Rest des Takts rückt nach)
LeertasteAbspielen ab der markierten Note / Stopp
Strg+Z / YRückgängig / Wiederholen
EscMarkierung aufheben

Rot hinterlegte Takte enthalten zu viele oder zu wenige Schläge – dort hat sich die Erkennung meist bei einem Notenwert geirrt.
